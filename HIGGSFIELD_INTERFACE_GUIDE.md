## 🆘 Troubleshooting

### "Can't find Higgsfield model"
- Scroll down the right panel
- Look for the sparkle icon ⭐
- Click on it to select

### "Generate button is grayed out"
- Make sure you've entered a prompt
- Check if you have enough credits
- Try refreshing the page

### "Video quality is low"
- Make sure Resolution is set to 1080p or 4K
- Keep "Enhance on" enabled
- Try a more detailed prompt

### "Don't have enough credits"
- Check your account balance
- You might need to purchase more credits
- Or try a cheaper model like "Minimax Hailuo"
